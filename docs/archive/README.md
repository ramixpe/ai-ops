# Archive — completed process documents

These did their job and are no longer live reference. They are **kept, not
deleted**, for one reason: each is the record of an *intention*, and this
project's method is that what was intended is what makes what happened
meaningful. Several are cited by `FINDINGS.md` entries that would otherwise
dangle.

current state read `docs/build/BACKLOG.md`, `docs/build/TRACKER.md` and
`docs/build/SESSION-HANDOVER.md`.
