What this tool writes down, and who gets to say it was right

Every run mints a run_id that ties its Markdown flight recorder to one line in the diagnosis ledger. Evidence, metrics, and a one-turn session pointer sit alongside — the ledger's own split is the one that matters: the tool records what it diagnosed, and only a human, later, records whether it was right.
