A syslog line now reaches the descent — through a gate that is shut

As of today the event path is wired end to end: a routed, non-recovery syslog line can drive the same deterministic descent the CLI and MCP paths use, with MiniMax choosing only which tool to call. Code supplies every identifier — the model is handed a schema with no field to name one. Chosen over a data-flow layout because the interesting part is temporal: a bounded, repeating negotiation between the model and the code refusing it, not a static pipeline.
