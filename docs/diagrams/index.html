Sixteen views of a read-only network inspection tool

Hand-authored with the diagram-design skill, describing the system end to end as it stood on 2026-08-27 — the tool, the lab platform it runs beside, and the fabric it reads. Every figure in them was derived from the tree or measured against the running system at build time, not recalled. Updated 2026-08-27 for the durable event store, the containerized authenticated-HTTP MCP transport, and the three tickets (B-706/707/717) that closed since the last pass.

This is one layer now, not two.

Until 2026-08-23 this directory held a generated, byte-pinned SVG set (regenerated and checked by CI on every change) alongside a separate hand-authored presentation set — two systems describing the same tool, with the generated one treated as the tie-breaker when they disagreed. That split is retired. There is only this set now, and it is hand-authored, not generated — nothing regenerates it, nothing byte-pins it against the source, and no test fails if the code moves out from under it. That is a real trade against the old guarantee, made deliberately: one honest, maintained layer beats two, one of which quietly drifted anyway. Treat these as current as of the date above, not as continuously verified.
