ios-xr-nettools · call paths

Four ways in, one boundary

A human at the CLI, a local model over either MCP surface, or a syslog line with nobody watching — every one of the four paths into this tool is read-only, and every one of them passes through the same allowlist before a command ever reaches a device. The live event path (right) is the only one with no human present, and the only one that can page someone.
