# Diagrams

Nine SVGs describing this repository as it stands. Every number on them is
measured from the tree at generation time, not recalled or typed once and
left to rot — line counts from `wc -l`, tool names from the registered MCP
surfaces, the CLI subcommand list from `cli.build_parser()` itself, rung
names and counts from `flows.FLOWS`, the walk result and its rungs from an
actual `nettools investigate --from-fixtures` run, test/guard/backlog/
findings counts parsed or run fresh from `tests/`, `scripts/mutate_guards.py`
and `docs/build/*.md`. `docs/diagrams/facts.py` is where all of that
measurement lives; `d1.py`..`d9.py` only lay it out. A handful of numbers
that are genuinely not properties of the tree — a decision's date, a
worked-example's illustrative wall-clock figure — stay as literals, each
with a comment in the generator explaining why.

`tests/test_diagrams.py` regenerates every SVG and fails if the result
differs byte-for-byte from what is committed, the same way `test_docs.py`
pins the README's command list to the code — so a change that should have
come with a regeneration, and didn't, fails the suite instead of shipping.

They are regenerated by the scripts alongside them:

```bash
cd docs/diagrams && python3 d1.py   # …through d9.py
```

Layout itself has no dependency beyond the standard library (`svgkit.py` is a
~140-line local helper). Measuring the tree does, now that there is something
to measure it with: `facts.py` imports this repo's own `agent_nettools` and
`mcp_server` packages (so `pip install -e ".[dev,llm]"` first — the same
`make setup` every other workflow in this repo needs) and shells out to `git`
and to `pytest` itself for the counts only a real run can answer. Rendering a
PNG to check one by eye needs `cairosvg`, which is still not a project
dependency — install it ad hoc if you want it.

**If you change the code, regenerate these rather than editing the SVGs.** A
diagram that is hand-patched drifts from the tree exactly the way prose does,
and the 2026-08-18 docs-drift review found twenty of those.
