# Diagrams

Six SVGs describing this repository as it stands on 2026-08-18. Every number on
them was measured from the tree at generation time, not recalled — line counts
from `wc -l`, tool names from the registered surfaces, rung names from
`flows.flow_for()`, the walk result from an actual `--from-fixtures` run.

| File | What it answers |
|---|---|
| [`01-repo-anatomy.svg`](01-repo-anatomy.svg) | **Where does the code live?** The layer stack from entry points down to the devices, every module with its size, and where each of the four invariants is enforced |
| [`02-call-path.svg`](02-call-path.svg) | **What happens when I run a command?** One `nettools investigate` traced through all eight stages, with the real output beside it |
| [`03-trust-boundary.svg`](03-trust-boundary.svg) | **How does device text reach a model, and why is that safe?** The projector's three rules, all five egress paths, and the honest residual |
| [`04-capabilities.svg`](04-capabilities.svg) | **What can it do?** All 31 subcommands grouped by purpose, both MCP surfaces, and which commands work with no lab at all |
| [`05-current-state.svg`](05-current-state.svg) | **Where are we?** Build stage, test/guard/backlog counts, what is waiting on the operator, and what the last five waves taught |
| [`06-descent.svg`](06-descent.svg) | **How is a diagnosis actually reached?** The three-tier composition hierarchy and the bgp_session ladder, rung by rung |
| [`07-stage2-architecture.svg`](07-stage2-architecture.svg) | **Where are we going?** The Stage 2 SOTA application as decided 2026-08-18 — the MCP hub, the wide→narrow gradient, the epoch-aware cache, and the live observability stack |

They are regenerated by the scripts alongside them:

```bash
cd docs/diagrams && python3 d1.py   # …through d6.py
```

The scripts have no dependencies beyond the standard library (`svgkit.py` is a
~120-line local helper). Rendering a PNG to check one by eye needs `cairosvg`,
which is not a project dependency — install it ad hoc if you want it.

**If you change the code, regenerate these rather than editing the SVGs.** A
diagram that is hand-patched drifts from the tree exactly the way prose does,
and the 2026-08-18 docs-drift review found twenty of those.
