ios-xr-nettools · model boundary

What a model may supply, what a model may see

A model never supplies a device, a peer address, or an interface name — those are pinned from the caller's own context and deleted from the schema before the model ever sees it, leaving only a closed, enumerated vocabulary to choose from. On the way back, every raw command result is withheld at the same registration point that runs the B-703 validation gates. lookup_lab — the one staged tool with no enumerated-only shape — is excluded from every offer entirely, not narrowed.
